### 💡 My Explanation

**DNS (Domain Name System)** translates domain names into IP addresses.

Think of it as a directory that helps computers find the server associated with a domain.

```text
User enters:

google.com
     ↓
DNS Lookup
     ↓
IP Address
     ↓
Browser connects to server
```
