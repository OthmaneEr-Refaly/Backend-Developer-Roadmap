 ### My Explanation
 
 [HTTP]: stand for hyper text transfer protocol which is a set of rule or a way of communications between the web server and the client, where the HTTP send a request to the server and the server send back a response "HTTP request/response cycle".
 ---> [Stateless]: Every request is completely independent of the other requests. this called "Stateless".
 ---> We use [Local storage, Cookies, Sessions] to help us walk through the statelessness of the HTTP.

3. What is web hosting ?
### Resources

[Youtube Video](https://www.youtube.com/watch?v=AXVZYzw8geg)

### My Explanation

Earlier we said that domain name is an address to your website, well no one can access your website if is not hosted.  

[Web hosting]: is a service that allows you to store your website files on a server and make them accessible to users on the internet.

---> [Shared Hosting]: You share a server with other websites, this is the cheapest option.
---> [VPS Hosting]: You have a virtual private server, this is a good option for small businesses.
---> [Dedicated Hosting]: You have a dedicated server, this is the most expensive option.
---> [Cloud Hosting]: You use a cloud computing platform, this is a good option for large businesses.
